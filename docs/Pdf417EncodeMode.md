# Pdf417EncodeMode

PDF417 barcode encode mode. Mirrors https://reference.aspose.com/barcode/net/aspose.barcode.generation/pdf417encodemode/
## Allowable values

* **Pdf417EncodeMode.AUTO**
* Pdf417EncodeMode.BINARY
* Pdf417EncodeMode.ECI
* Pdf417EncodeMode.EXTENDED
